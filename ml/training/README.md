# ML Training

Contains model training scripts:

1. **Vision Baselines**: Classification and object detection baselines (e.g. lightweight CNN / YOLO).
2. **Text Baselines**: TF-IDF + linear classifier baseline, followed by sentence embeddings.
3. **Multimodal Fusion**: Concatenation and cross-attention architectures combining visual and textual features.

*Training pipelines will be introduced incrementally starting in Sprint 3.*
