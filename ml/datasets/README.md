# ML Datasets

This directory will store dataset manifests, download scripts, and schema annotations for civic datasets.

## Candidate Datasets
- **RDD2022**: Multi-country road damage dataset covering potholes, cracks, and surface degradation.
- **TACO**: Trash Annotations in Context for civic garbage accumulation.
- **Project Domain Curations**: Supplemental local civic imagery with human-verified annotations.

*No datasets are downloaded or committed in Phase 0.*
